Command Center v3.0 Cloud｜安全線目標分配版

本版更新：
1. 設定頁新增「安全達成率」，預設 80%。
2. 可選每日／每週目標依 80% 安全線或 100% 完整目標分配。
3. Dashboard 同時顯示安全線與完整目標差距。
4. 星期日會議、每週目標、今日目標圖會依選定分配基準計算。
5. 對應表維持放在業績追蹤 Excel 的「對應表」工作表。
6. Accy(NA) 維持固定公式：AG=Accy 的 I 欄金額，扣除 AH=AirPods 的 I 欄金額。

部署：將所有檔案與 assets 資料夾完整覆蓋 GitHub Pages 專案根目錄。
手機若仍看到舊版，請移除主畫面捷徑、重新整理網站後再加入主畫面。

v3.0 人員綽號功能
- 到「基本設定 → 人員顯示設定」輸入每位人員的綽號。
- 可選擇只顯示綽號、綽號＋正式姓名、只顯示正式姓名。
- 工號仍作為資料比對依據，不會因修改綽號影響匯入。
- 設定會透過 Firebase 同步至手機與電腦。
