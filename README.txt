Command Center v3.2.5｜每日需求與落後差距整數化修正版

本版變更：
- 「剩餘每日需完成」不再顯示小數，全部無條件進位。
- 件數型每日需求最低顯示 1。
- 「落後差距」同步改為無條件進位，不再顯示小數，最低 1。
- 首頁／今日重點中顯示的「每日需」同步採用相同整數規則。
- Accy(NA) 金額型數值亦採無條件進位為整數；達標後隱藏的既有規則維持不變。
- 其餘 KPI、Firebase、庫存巡檢、展示清冊與週報邏輯不變。

部署方式：將本資料夾所有檔案與 assets 資料夾完整覆蓋 GitHub Pages 專案根目錄。

Command Center v3.2.7
- 修正落後追蹤計算：落後差距以公司目前應達進度與個人實績的差額計算。
- 剩餘每日需完成改為「落後差距 ÷ 個人剩餘工作日」，並無條件進位。
- 落後差距改顯示正數，不再以負號呈現。
- 其他 KPI、Firebase、庫存巡檢、展示清冊功能維持不變。


v3.2.7 支援人員判斷修正：
- Data／門號表中出現、但不在本店班表／目標正式名單的人員，視為支援人員。
- 支援人員實績仍計入全店 KPI。
- 支援人員不列入個人目標、落後追蹤、週目標與正式人員名單。
