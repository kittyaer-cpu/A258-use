板橋戰情中心 v2.1.0

部署方式：
1. 將本資料夾內所有檔案上傳至 GitHub Repository 根目錄。
2. GitHub Settings → Pages → Deploy from a branch。
3. 選擇 main 與 /root 後儲存。
4. 部署完成後重新整理網站；若仍看到舊版，請清除 Safari 網站資料或移除舊主畫面捷徑後重新加入。

v2.1 新增：
- Dashboard 2.0
- 店長專屬規則式 AI 分析
- 今日最低目標
- 今日個人目標總覽
- 今日警示與追蹤
- 每日戰情 PNG 圖卡（不含系統名稱、Logo、更新時間、資料來源及 AI 建議）
- 同一天重複匯入時顯示本次數字變化

注意：
- Excel 解析與 PNG 輸出元件由 CDN 載入，第一次使用需連線。
- 匯入後請重新產生圖卡，圖卡會依最新資料更新。
