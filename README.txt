板橋戰情中心 v2.3 Cloud
========================

本版保留 v3.0.1 的既有功能與畫面，只新增 Firebase Firestore 雲端同步。

部署方式
1. 將本資料夾全部檔案上傳並覆蓋 GitHub Pages 儲存庫根目錄。
2. 等 GitHub Pages 更新完成後，重新開啟網站。
3. 手機與電腦第一次開啟時，各輸入一次 Firebase Authentication 管理帳號。
4. 登入狀態會保留，後續直接開啟即可。

同步方式
- 系統仍會先保存一份本機快取，操作不會因短暫斷線而遺失。
- 登入並連線後，資料會保存到 Firestore：stores/banqiao/appState/main
- 手機與電腦使用同一 Firebase 帳號後，會讀取同一份資料。
- 畫面上方「雲端已同步」代表同步正常。

重要提醒
- Firestore Rules 必須允許已建立的 Firebase 管理帳號讀寫。
- 第一次在原本有資料的電腦登入時，若雲端尚無資料，系統會將本機資料上傳。
- 第二台裝置登入後，會下載雲端資料。
- 請勿同時在兩台裝置快速大量修改同一份設定，以最後一次成功同步為準。
