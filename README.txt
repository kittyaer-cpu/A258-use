Command Center v3.2.3｜每日最低目標修正版

基於 v3.2.2 庫存巡檢中心正式測試版。

本次修正：
1. 今日目標的件數型 KPI（總保險、總門號、GA／NP、999以上），只要人員今天有上班，每人每日目標最低為 1；即使月達成率已達 100% 或以上也維持最低 1。
2. 原公式若計算高於 1，仍保留原本較高的目標，不會全部改成 1。
3. Accy(NA) 採例外規則：全店尚未達 100% 月目標前持續分配；全店達標後，自動從「今日最低目標」及「今日目標圖」隱藏。
4. 個人 Accy(NA) 已達個人月目標時，以「—」顯示，不再產生 0 金額。
5. 今日目標圖的全店數字改為依當日實際個人最低目標加總，確保件數型 KPI 不會因公司進度超前而顯示 0。
6. 保留 v3.2.2 的庫存巡檢、配件展示清冊、手機掃描、Firebase 同步與店長週報邏輯。

部署：將本資料夾全部內容覆蓋 GitHub Pages 儲存庫根目錄。若手機仍載入舊版，請重新整理；必要時移除主畫面捷徑後重新加入。
