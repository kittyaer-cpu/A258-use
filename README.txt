Command Center v3.2.2｜庫存巡檢中心

新增：
1. 隨機抽盤：一次可加入不限數量品項，記錄料號/EAN、品名、目前庫存、實際庫存、差異、時間與抽盤人。
2. 配件展示清冊：建立固定展示品名單、展示數量、狀態、最後盤點時間。
3. 展示抽盤：自動帶出展示中清冊，逐項確認實際數量並保留歷史紀錄。
4. 手機掃描：支援料號條碼、EAN-13、Code 128/39；掃描只在手機版顯示，若相機不支援可手動輸入。
5. Firebase 同步：巡檢資料與原本系統資料一起同步。

部署：將本資料夾全部內容覆蓋 GitHub Pages 儲存庫根目錄。首次使用相機時請允許網站存取相機。
