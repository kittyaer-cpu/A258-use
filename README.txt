板橋戰情中心 v2.2

部署方式：
1. 將本資料夾內所有檔案上傳至 GitHub Repository 根目錄。
2. GitHub Settings → Pages → Deploy from a branch。
3. Branch 選 main，資料夾選 /root，儲存。
4. 部署完成後重新整理網站。

v2.2 新增：
- 星期日會議模式
- 本週全店 KPI 與落後人員
- 店長分析
- 每人改善事項與下週改善紀錄
- 下週目標總覽
- 會議 CSV 匯出
- 列印／存 PDF
- 店長週報自動生成
- 週報 TXT 下載與列印／存 PDF

資料沿用：
