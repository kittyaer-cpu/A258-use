板橋戰情中心 v2.2.5｜智慧排班中心

部署方式：
1. 將本資料夾所有檔案上傳至 GitHub Pages 專案根目錄。
2. 覆蓋舊版 index.html、styles.css、app.js、manifest.json、sw.js。
3. 重新整理；Safari 若仍顯示舊版，請清除網站資料或移除主畫面捷徑後重新加入。

本版新增：
- 匯入排班 Excel（第一張工作表，A欄工號、B欄姓名、D欄起為1～31日）。
- N8／D6／A4 算上班；SR／SS／U 不算上班。
- 特休、病假、事假、其他請假可依日期手動覆蓋。
- 店長工號預設 5052，可在排班中心修改。
- 店長計入當日總人力，但不顯示個人業績、個人目標、落後名單及會議追蹤。
- 店長業績仍計入全店 KPI 總計。
- 每週目標改為只設定全店目標。
- 今日個人目標只分配給當日上班的非店長人員。
