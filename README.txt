板橋戰情中心 v3.0｜部署說明

一、部署
1. 將此資料夾內全部檔案上傳到 GitHub Pages 儲存庫根目錄。
2. 覆蓋舊版 index.html、app.js、styles.css、manifest.json、sw.js。
3. 部署後重新整理；Safari 若仍顯示舊版，請清除網站資料或移除舊主畫面捷徑後重加。

二、每月一次
按「匯入班表／目標／進度.xlsx」，選擇正式格式檔案。必須包含：
- 班表
- 進度表
- 本月目標
- 設定

系統會讀取：
- 班別與每日排班
- Manager／Staff 角色
- 全店及個人月目標
- 公司每日累計進度與日進度權重
- 店長是否計入 KPI、人力、目標與追蹤等設定

三、每日
按「匯入業績追蹤.xlsx」。系統固定讀取：
- Data
- 對應表
- 門號表
- 人員表

四、V3 計算規則
- 今日公司應達：月目標 × 公司累計進度，扣除目前實績。
- 本週原定目標：月目標 × 該週日進度權重合計。
- 本週追趕目標：原定週目標＋前週累積落後（依設定）。
- 個人今日目標：依今日上班人員的個人月缺口比例分配。
- N8／D6／A4 算上班；SS／SR／SH／U 不算，實際以「設定」工作表為準。
- 特休、病假、事假等可在排班中心手動覆蓋。

五、圖卡調整
「今日目標圖」已移除右上角週次與底部人力，只保留日期、全店今日目標與個人今日目標。
